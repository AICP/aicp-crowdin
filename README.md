# crowdin_sync.py

## Introduction

This script is forked and modified from LineageOS. It is used to synchronize AICP translations with Crowdin.
It can handle automatic commiting to AICP's Gerrit, submitting or voting on open commits as well as pushing/downloading to/from Crowdin.

## Prerequisites

1. Java runtime environment 17.x.x is needed to run the crowdin-cli tool.
2. Python version >3.14.x is needed to execute this script (as it is necessary for building the sources anyway).
3. The package "python-lxml" is used for removing empty or faulty translations after download. So it needs to be installed on the system. (also see: https://lxml.de/)
4. The package "python-yaml" must be installed as it is used for parsing the YAML configuration files for determining which files to push.
5. The package "python-git" is used for Git integration and must be installed for example via <code>pip install Gitpython</code> (also see: https://gitpython.readthedocs.io/en/stable/).
6. The install of the package "python-gitdb" with its dependencies via a package manager or via <code>pip install gitdb</code> for python 3.x.x.
7. A Java version of crowdin-cli >= 4.14.x or a packaged version (see: https://support.crowdin.com/cli-tool/) is required for this script to work.
   It can be downloaded and installed for different Linux distributions as described on the mentioned webpage.
   *Note: The current limitation is that the script will search for an executable (alias) using the "which" command on a Linux/macOS installation.*
8. Currently the crowdin-cli tool requires either Windows10/11 WSL2, macOS or Linux to work.
9. The file <code>w16.2_extra_packages.xml</code> and <code>/config/w16.2_crowdin.xml</code> must reside in the directory <code>/config</code> in the main source directory (e.g."/aicp").
   This makes sure you will sync all the translatable and extra packages.
   **Please remember that you should comment out packages in <code>w16.2_extra_packages.xml</code> that you already have in your local `aicp_manifest.xml` file as these are device and version dependent. Doubled entries might otherwise lead to syncing errors using the repo command.**

Note: You can also try (depending on your OS) to install the needed dependencies via the "requirements.txt" provided in this repository by running the following command:

    pip install -r requirements.txt

## Executing

Export the needed environment variables to set the API key and the base path to your **.zshrc**, **.bashrc** or **.bash-profile**.
The base path should contain all AICP trees in subfolders, named after AICP branches.

Needed directory structure:

<pre>
    <code>home/
    your_username/
      aicp/
        crowdin_sync.py                     #Python main script for the crowdin-CLI tool
        download.py                         #Python sub script for downloading sources from Crowdin
        from_zip.py                         #Python sub script for extracting translations from a locally stored ZIP archive
        gerrit.py                           #Python sub script providing Gerrit review subrountines for pushing/voting/abandoning translation commits
        upload.py                           #Python sub script used by the main script for uploading sources to Crowdin
        utils.py                            #Python sub script providing basic subrountines for the scripts above
        config/
            w16.2.yaml                      #Configuration file for the translatable repositories
            w16.2_crowdin.xml               #Manifest file (used by the script)
            w16.2_extra_packages.xml        #Manifest snippet containing device specific repositories hat are translated
        w16.2/                              
    </code>
</pre>

#### Enviroment variables to export:
```
    export AICP_CROWDIN_API_TOKEN=your_aicp_personal-access-token       #must be generated by you and will be displayed ONLY ONCE afterwards!
    export AICP_CROWDIN_BASE_PATH_W16_2=your_base_path_and_branch
```
#### Example:
```
    export AICP_CROWDIN_API_TOKEN=68f83--your-personal-token--...       #Open profile settings and go to API & SSO > New Token > create Token
    export AICP_CROWDIN_BASE_PATH_W16_2=/home/your_username/aicp/w16.2  #This is dependent on the real path to your source tree (e.g. '/aicp/w16.2')
```
#### Execute:

The python scripts and the "config" directory should be copied into the base folder structure, e.g. /home/your_username/aicp, like shown above.
The script's incorporated commandline arguments that can be invoked are:

<code>
  crowdin_sync.py [-h] [-u USERNAME] -b BRANCH [-c CONFIG] [--upload-sources] [--upload-translations] [--download]
                       [-g {abandon,vote,submit}] [-m MESSAGE] [-o OWNER] [-U UPLOADER] [-p PATH-TO-CROWDIN] [--unzip UNZIP [UNZIP ...]]
</code>


#### Explanation of the usage arguments:
```
  -h or --help                    #Show the help message and exit

  -b or --branch BRANCH           #AICP branch (REQUIRED)
  -c or --config CONFIG           #Custom .yaml config file to use instead of the default "w16.2.yaml" (OPTIONAL)
  -p or --path-to-crowdin         #Path to crowdin executable (OPTIONAL, the script will search the PATH variable by default)

  --upload-sources                #Upload sources to AICP Crowdin
  --upload-translations           #Upload AICP translations to Crowdin from sources on your PC

  -u or --username USERNAME       #AICP Gerrit username (REQUIRED, if not stored in your ".github" config for pushing to AICP's Gerrit)
                                  #The USERNAME is needed for all following script actions: 

  --download                      #Download AICP translations from Crowdin AND push them to AICP Gerrit
  --unzip "/path/file.ZIP"        #Specify a locally saved "AICP (translations).zip" archive from Crowdin and treat it like a download,
                                  #adding the translations to your sources AND uploading them (after a cleanup) to AICP's Gerrit.

  -g or --gerrit abandon          #Abandon open translation commits on AICP Gerrit
  -g or --gerrit vote             #Vote (CR+1/V+1) on open translation commits on AICP Gerrit
  -g or --gerrit submit           #Submit (incl. CR+2/V+1) open translation commits on AICP Gerrit
  -m or --message "Text"          #Specify the Gerrit abandon/vote message
  -o or --owner "full name"       #Specify the owner of the commits to submit
  -U or --uploader "full name"    #Specify the uploader of the commits to submit

```
Examples:

<code>./crowdin_sync.py --branch w16.2 --upload-sources</code><br />

Will upload specified local files from the YAML-config to Crowdin. Translations already there will be preserved.

<code>./crowdin_sync.py --branch w16.2 --upload-translations</code><br />

Will upload local translations to Crowdin, based on YAML-config and from your local sources.

<code>./crowdin_sync.py --username Gerrit-Username --branch w16.2 --download</code><br />

Will download translations from Crowdin for the specified branch (w16.2), based on YAML-config, to your local sources, 
delete empty translations and upload updated or new translations to AICP's Gerrit for review.

<code>./crowdin_sync.py --username Gerrit-Username --branch w16.2 --unzip "/path/AICP (translations).zip"</code><br />

Will unzip and extract downloaded translations ZIP-file from Crowdin for the specified branch (w16.2) based on YAML-config to your local sources and delete empty translations. 
After this it will push these translations to AICP's Gerrit for review.

<code>./crowdin_sync.py --username Gerrit-Username --branch w16.2 --gerrit abandon --message 'Did not work out'<br />
./crowdin_sync.py --username Gerrit-Username --branch w16.2 --gerrit vote --message 'It works!'</code><br />

Will search for open translations commits on AICP's Gerrit on the specified branch (w16.2) and automatically abandon or upvote all of them. 
This is a helper to bulk upvote (CR+1/V+1) or abandon open commits.
The optional "<code>--message 'Text'</code>" argument offers the possibility to add a message for why the commit was abandoned.

<code>./crowdin_sync.py --username Gerrit-Username --branch w16.2 --gerrit submit --owner 'John Doe'<br />
./crowdin_sync.py --username Gerrit-Username --branch w16.2 --gerrit submit --owner 'John Doe' --uploader 'Tim Tale'</code><br />

Will search for open translations commits on AICP's Gerrit on the specified branch (w16.2) and
automatically submit (incl. CR+2/V+1) them into the repositories. This is useful after successful builds and a helper to bulk merge commits for Gerrit Admins.
**It requires Gerrit Admin rights to preform this action.**
The optional "<code>--owner 'Name'</code>" or "<code>--uploader 'Name'</code>" arguments filter the submitted files by the name of its owner and/or uploader, so AICP can make sure that no accidental merges happen.


##### Notes:

 - The scripts and the crowdin-cli JAR file provide some output that show off the actions performed
   in the terminal, so you can follow the execution of the commands.
 - The crowdin-cli JAR file will display a message in the terminal, if it is outdated and found a
   newer version available for download. This is not an error, just a reminder for you!
 - **When committing a translation fails, the reason for that cannot be determined everytime. The script will simply display the message "Failed: " and an error message mentioning what went wrong.
   The script will try to continue when this happens and display "Nothing to commit".**
